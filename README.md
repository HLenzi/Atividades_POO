# Atividades de Programação Orientada a Objetos

Este repositório reúne exercícios, avaliações e o trabalho final desenvolvidos durante a disciplina de Programação Orientada a Objetos do segundo semestre do curso de Ciências da Computação, utilizando a linguagem Java.

# Conteúdos praticados durante a disciplina

- Criação e utilização de classes e objetos.
- Encapsulamento e modificadores de acesso.
- Construtores, atributos e métodos.
- Herança e polimorfismo.
- Introdução à UML e diagrama de classes.
- Tratamento de exceções.
- Desenvolvimento de interfaces gráficas em Java.
- Testes unitários, casos de teste e assertivas.
- Leitura e escrita em arquivos.
- Persistência de dados entre execuções de um programa

# Observações
- Algumas atividades desenvolvidas durante a disciplina não estão presentes neste repositório.
- O enunciado está disponível apenas para o trabalho final.
