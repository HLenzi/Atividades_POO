# Sistema de Controle Financeiro Pessoal

Aplicação desktop desenvolvida em Java como trabalho final da disciplina de Programação Orientada a Objetos, com o objetivo de auxiliar no controle de receitas e despesas domésticas.

## Funcionalidades

- Cadastro de receitas com data, valor e categoria.
- Cadastro de despesas com data, valor e categoria.
- Consulta do saldo atual, considerando lançamentos até a data presente.
- Consulta do saldo total, considerando todos os lançamentos.
- Listagem de receitas e despesas separadamente.
- Geração de extrato com receitas e despesas ordenadas por data e apresentação do saldo acumulado.
- Armazenamento e recuperação dos dados por meio de arquivos CSV.

## Conceitos aplicados

- Programação Orientada a Objetos.
- Classes abstratas e herança.
- Encapsulamento e validação de dados.
- Enumerações para representar categorias financeiras.
- Tratamento de exceções.
- Manipulação de arquivos e persistência de dados.
- Coleções com `ArrayList`.
- Manipulação de datas com `LocalDate`.
- Programação orientada a eventos.

## Tecnologias utilizadas

- **Linguagem:** Java
- **Interface gráfica:** Java Swing
- **Ambiente de desenvolvimento:** NetBeans
- **Persistência:** arquivos CSV

## Contexto acadêmico

Trabalho desenvolvido em equipe para a disciplina de Programação Orientada a Objetos do curso de Ciências da Computação.
